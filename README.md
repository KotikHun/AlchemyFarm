# Alchemy Farm

Игра на C++ / SFML: фермерство, магические растения, животные и варка зелий.

## О проекте

Alchemy Farm — 2D-игра в жанре фермерского симулятора с элементами алхимии. Игрок выращивает магические растения, ухаживает за животными и варит зелья по рецептам. Вместо простой продажи — система заказов от NPC.

Вдохновение: Stardew Valley, Graveyard Keeper, Sun Haven.

## Стек

- **C++20**
- **SFML 3.0.2** — графика, окно, ввод
- **vcpkg** — управление зависимостями
- **Visual Studio 2026** — сборка
- **MSBuild** (не CMake)
- **Git** — контроль версий

## Как собрать

### Требования

- Visual Studio 2026 (или 2022) с компонентом «Разработка классических приложений на C++»
- vcpkg (встроен в VS 2026)
- Git

### Шаги

1. Клонировать репозиторий:

   ```
   git clone https://github.com/KotikHun/AlchemyFarm.git
   cd AlchemyFarm
   ```

2. Установить зависимости (SFML и его библиотеки):

   ```
   vcpkg install
   ```

   vcpkg прочитает `vcpkg.json` и поставит всё автоматически.

3. Открыть `AlchemyFarm.slnx` в Visual Studio.

4. Собрать: **Ctrl+Shift+B**.

5. Запустить: **F5**.

## Управление

- **WASD** — ходьба
- **1, 2, 3, 4** — выбор инструмента (мотыга, семечко, лейка, рука)
- **E** — взаимодействие с тайлом перед игроком
